# Student Expense Analysis 

## Overview
This project analyzes personal expense data to understand spending behavior, daily trends, category-wise distribution, and payment method usage.  
Python was used for data cleaning and analysis, and Tableau was used to create an interactive dashboard.

## Tools & Technologies
- Python (Pandas, NumPy, Matplotlib)
- Tableau Public
- Jupyter Notebook

## Project Structure

Student-Expense-Analysis/

  ├── expense_analysis.ipynb 
  ├── expense_data_cleaned.csv
  ├── category_spending_summary.csv

## Key Analysis Performed
- Cleaned and prepared raw expense data using Pandas
- Analyzed category-wise spending patterns
- Studied daily expense trends
- Analyzed usage of different payment methods (Cash / UPI / Card)

## Tableau Dashboard
An interactive Tableau dashboard was created to visualize:
- Category-wise spending
- Daily expense trends
- Payment method usage

🔗 **Dashboard Link:** https://public.tableau.com/views/StudentExpenseAnalysis/Dashboard1?:language=en-US&publish=yes&:sid=&:redirect=auth&:display_count=n&:origin=viz_share_link

## Insights
- Certain categories contribute significantly to total expenses
- Daily expense patterns show fluctuations rather than uniform spending
- Digital payment methods are used more frequently than cash

## Conclusion

This project demonstrates end-to-end data analysis skills, from data preprocessing in Python to business-focused visualization using Tableau.
